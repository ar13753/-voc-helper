고객의 소리(VOC)를 유형별로 분석하고
응대 초안을 자동으로 작성하는 도구입니다.

⬇ 안드로이드 앱 다운로드 (APK) 🌐 아이폰 / 웹으로 바로 열기

설치 방법 (안드로이드)

  1. 위 버튼을 눌러 APK 파일을 다운로드합니다.
  2. 다운로드 완료 알림을 눌러 설치를 시작합니다.
  3. "출처를 알 수 없는 앱" 경고가 뜨면 설정 → 허용 후 다시 설치를 진행합니다.
  4. 설치가 끝나면 홈 화면에서 sol-mate 아이콘을 실행하세요.

기존에 "VOC도우미" 앱을 설치하셨던 분은 새 서명키로 다시 빌드되어, 업데이트 설치가 아니라 기존 앱을 먼저 삭제한 뒤 새로 설치해야 합니다.
